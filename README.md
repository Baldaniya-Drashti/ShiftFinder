# ShiftFinder App
``
ShiftFinder is a comprehensive healthcare marketplace app that serves as a platform
connecting healthcare professionals with available shifts in various sectors such as
pharmacy, dental, hospitality, and general healthcare. The app caters to the needs of both
healthcare facilities and professionals, streamlining the process of filling temporary
staffing gaps and finding suitable work opportunities.``

##### Here is the folder structure we have been using in this project

```sh
lib/

|-application/  
    - Contains Bloc state management for handling business logic.
    - Includes `.freezed.dart` and `.g.dart` files generated by `freezed` and `json_serializable`.
    - Manages authentication, user actions, and other app-level logic.

|-domain/  
    - Defines core business rules, failure handling, and entities.  
    - Works as an intermediary between `application` and `infrastructure`.  
    - Contains abstract classes for repositories and models used across the app.  

    |-core/  
        - Contains shared utilities, constants, and reusable helper functions.
        - Defines failures and error handling strategies.

|-infrastructure/  
    - Implements data handling logic such as API calls.  
    - Also contains Models and Communicates with repositories in `domain/` to fetch and store data.  
    |-core/
        |-network/
            - Provides base classes and shared configurations for networking, database access, and other services.
            |-interceptor
                - Interceptors, including auth, request, and response interceptors.

|-presentation/  
    - Contains UI elements such as screens, widgets, and themes.
    - Uses Flutter widgets to display data handled by `application` and `domain`.
    - Divided into different modules like authentication, main, etc.
    |-core/  
        - Holds shared UI components such as themes, styles, and typography.
        - Contains base classes for widgets and common UI utilities.
        - Manages notifiation navigation and route handling across the app.
        |-helper/  
            - Includes extensions, formatters, and notifications helper methods.
        |-widgets/  
            - Includes custom buttons, text fields, loaders, dialogs, and other shared widgets.
        |-app_router.dart  
            - Defines named routes and handles screen navigation. 
        |-app_widget.dart  
                - Serves as the root widget of the application.  
                - Wrap the entire app with providers such as `BlocProvider` or `MultiProvider`.  
                - Entry point for rendering the UI.
        |-restart_widget.dart 
            - Wraps the app’s root widget to allow resetting its state dynamically.  
    |-common/  
        - Includes reusable UI elements such as buttons, dialogs, and loaders.
        - Manages shared preferences, SQFLite, or Hive for persistent data storage.

|-injection.dart
        - Uses `get_it` or another DI package to register and provide services, repositories, and blocs.

|-setup_hive.dart  
        - Registers Hive adapters for custom data types.  
        - Opens and manages Hive boxes for persistent data storage. 
        
|-main.dart  
    - The entry point of the application.
    - Initializes dependencies and runs the app.
```



##### Using Google api's in project

```sh

- place/autocomplete/json → Suggests locations as users type.
- place/details/json → Retrieves coordinates of a place.

Google_Geocoding_API
- geocode/json → Converts lat/lng to an address.

Google_Maps_Directions_(URL-based_Navigation)
- Launches Google Maps for route navigation.
- https://www.google.com/maps/dir/?api=1 → Android
``` 
